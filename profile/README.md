# Plan Net Journey

Skills, Agents und Projekt-Assets fuer datengetriebene Customer Journeys.

## Gerade beigetreten? Zwei Schritte.

**1. Claude Code installieren** — [claude.ai/download](https://claude.ai/download)

Die Desktop-App. Nicht verwechseln mit der normalen Claude Chat-App, das ist etwas anderes.

**2. Oeffnen und diesen Satz sagen:**

> Lade das Repo plan-net-journey/.github herunter und fuehre mich durch das Onboarding.

Claude macht den Rest — Zugaenge, Schluessel, Werkzeuge. Was du schon hast, wird
uebersprungen. Du brauchst kein Vorwissen und musst nichts selbst im Terminal tippen.

Dauert etwa fuenfzehn Minuten.
