# Sicherheit

## Token, Passwort oder API-Key geleakt?

Sofort an das **Maintainer-Team** melden: @plan-net-journey/maintainers

- **Nicht** erst ein Ticket erstellen — direkt melden
- **Nicht** den Token selbst versuchen zu loeschen — Maintainer machen das
- Je schneller die Meldung, desto kleiner der Schaden

## Was die Maintainer dann tun

1. Token sofort revoken (ungueltig machen)
2. Neuen Token erstellen und Secrets aktualisieren
3. Pruefen ob der Token missbraucht wurde
