Anleitung fuer Teammitglieder

Alles was du brauchst um mit den PNJ Skills und Projekten zu arbeiten.

Erste Schritte

So richtest du dich ein

Zwei Schritte — danach bist du startklar.

1 Claude Code installieren

Lade die Claude Code Desktop App herunter und installiere sie wie jede andere App. Nicht verwechseln mit der normalen Claude Chat-App — Claude Code kann mit Dateien auf deinem Rechner arbeiten.

Download: claude.ai/download

↓

2 Onboarding durchlaufen

Oeffne Claude Code und sage: "Lade das Repo plan-net-journey/.github herunter und fuehre mich durch das Onboarding" — Claude macht den Rest: GitHub Account, SSH Key, Zugang beantragen.

Onboarding-Seite auf GitHub

Nach dem Onboarding

PNJ Plugin installieren

Sobald du Zugang zur Organisation hast, installiere das PNJ Plugin. Damit hast du in jedem Projekt Zugriff auf Hilfe und Ticket-Erstellung.

In Claude Code eingeben:

/plugin marketplace add plan-net-journey/Journey-Skills
/plugin install pnj --scope user

Danach verfuegbar:

/pnj:hilfe — Hilfe und Erklaerungen

/pnj:ticket — Tickets erstellen (Projekt, Zugang, Feedback)

Updates holen

Wenn neue Skills dazukommen, einmal ausfuehren:

/plugin marketplace update

Projektstruktur

Wie Projekte aufgebaut sind

Jedes Projekt hat die gleiche Grundstruktur. Claude liest diese Dateien automatisch und versteht den Kontext.

Im Projektordner

CLAUDE.md — Beschreibt das Projekt fuer Claude. Wer ist der Kunde, welche Regeln gelten, wo liegen Dateien.

MEMORY.md — Was Claude sich ueber Sessions hinweg merkt: Entscheidungen, Learnings, Kontext.

.claude/skills/ — Skills die nur fuer dieses Projekt relevant sind.

Grosse Dateien

Videos, Praesentationen und andere grosse Dateien gehoeren nicht in den Projektordner.

Sie bleiben in eurem Cloud-Storage (Box, OneDrive) und werden per Symlink verknuepft:

ln -s /pfad/zum/cloud/ordner kontext

Die CLAUDE.md im Projekt beschreibt wo die Dateien liegen.

Regeln

Das gilt fuer alle

So machen wir es

✓ Alle Projekte sind privat
✓ Neue Projekte und Zugaenge immer per Ticket
✓ SSH Keys fuer die Verbindung zu GitHub
✓ Aenderungen per Pull Request
✓ Grosse Dateien per Symlink auf Cloud-Storage

Das machen wir nicht

✗ Oeffentliche Projekte erstellen
✗ Passwoerter oder Tokens committen
✗ Videos oder PPTX in den Projektordner
✗ Kundendaten in den Skills-Marketplace
✗ Direkt auf main pushen
