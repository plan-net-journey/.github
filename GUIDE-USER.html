Anleitung fuer
Teammitglieder

Alles was du brauchst um mit Skills, Projekten und dem Team zu arbeiten.

Erste Schritte

So startest du

1

Claude Code herunterladen

Lade die Claude Code Desktop App unter claude.ai/download herunter. Installieren wie jede andere App.

Nicht verwechseln mit der normalen Claude Chat-App — das ist etwas anderes.

2

Onboarding durchlaufen

Oeffne Claude Code und sage: "Lade das Repo plan-net-journey/.github herunter und fuehre mich durch das Onboarding."

Claude richtet alles fuer dich ein — Account, SSH Key, Zugang.

3

Plugin installieren

Nachdem du Org-Zugang hast, installiere das PNJ Plugin. Tippe in Claude Code:

/plugin marketplace add plan-net-journey/Journey-Skills

/plugin install pnj --scope user

Projekte

Wie Projekte funktionieren

Jedes Projekt ist ein Ordner mit einer klaren Struktur.

Projektstruktur

CLAUDE.md — Beschreibt das Projekt fuer Claude. Kontext, Regeln, Struktur. Claude liest diese Datei automatisch.

MEMORY.md — Index fuer gespeicherte Erinnerungen. Claude merkt sich Dinge zwischen Sessions.

.claude/skills/ — Skills die nur fuer dieses Projekt relevant sind.

Grosse Dateien

Videos, Praesentationen und andere grosse Dateien bleiben in eurem Cloud-Storage (Box, OneDrive).

Im Projekt wird per Symlink darauf verwiesen:

ln -s /pfad/cloud kontext

Marketplace Skills

50+ fertige Skills im Journey-Skills Marketplace — fuer alle Projekte nutzbar. Kampagnen, Content, Strategie und mehr.

Projekt-Skills

Skills die nur fuer einen Kunden relevant sind, leben im Kunden-Repo unter .claude/skills/.

Design Tokens

Jedes neue Projekt bekommt automatisch eine design.md mit Serviceplan Brand-Farben, Fonts und Grid-Regeln.

Regeln

Das gilt fuer alle

So arbeiten wir

  • Alle Projekte sind privat — nur Teammitglieder sehen sie
  • Neue Projekte und Zugaenge immer per Ticket
  • SSH Keys fuer Git-Zugang (wird im Onboarding eingerichtet)
  • Aenderungen ueber Pull Requests — nicht direkt auf main
  • Grosse Dateien per Symlink auf Cloud-Storage, nie ins Repo
