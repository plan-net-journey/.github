Anleitung für
Teammitglieder

Alles was du brauchst um mit Skills, Projekten und dem Team zu arbeiten.

Erste Schritte

So startest du

1

Claude Code herunterladen

Lade die Claude Code Desktop App unter claude.ai/download herunter. Installieren wie jede andere App.

Nicht verwechseln mit der normalen Claude Chat-App — das ist etwas anderes.

2

Onboarding durchlaufen

Öffne Claude Code und sage: "Lade das Repo plan-net-journey/.github herunter und führe mich durch das Onboarding."

Claude richtet alles für dich ein — Account, SSH Key, Zugang.

3

Plugin installieren

Nachdem du Org-Zugang hast, installiere das PNJ Plugin. Tippe in Claude Code:

/plugin marketplace add plan-net-journey/Journey-Skills

/plugin install pnj --scope user

Projekte

Wie Projekte funktionieren

Jedes Projekt ist ein Ordner mit einer klaren Struktur.

Projektstruktur

CLAUDE.md — Beschreibt das Projekt für Claude. Kontext, Regeln, Struktur. Claude liest diese Datei automatisch.

MEMORY.md — Index für gespeicherte Erinnerungen. Claude merkt sich Dinge zwischen Sessions.

.claude/skills/ — Skills die nur für dieses Projekt relevant sind.

Große Dateien

Videos, Präsentationen und andere große Dateien bleiben in eurem Cloud-Storage (Box, OneDrive).

Im Projekt wird per Symlink darauf verwiesen:

ln -s /pfad/cloud kontext

Marketplace Skills

50+ fertige Skills im Journey-Skills Marketplace — für alle Projekte nutzbar. Kampagnen, Content, Strategie und mehr.

Projekt-Skills

Skills die nur für einen Kunden relevant sind, leben im Kunden-Repo unter .claude/skills/.

Design Tokens

Jedes neue Projekt bekommt automatisch eine design.md mit Serviceplan Brand-Farben, Fonts und Grid-Regeln.

Aktuell bleiben

Updates kommen nicht von selbst

Einmal die Woche

Neue Skills und neue Versionen landen nicht automatisch bei dir. Der Marketplace wird nur geholt, wenn du ihn holst:

/plugin marketplace update

Danach installierst du neu dazugekommene Plugins wie gewohnt. Bestehende werden beim nächsten Start von Claude Code auf die neue Version gehoben.

Woran du es merkst

Jemand spricht von einem Skill, den es bei dir nicht gibt. Oder ein Skill verhält sich anders als beschrieben.

Dann hast du eine alte Version — einmal aktualisieren, Claude Code neu starten.

In Projekten aus dem project-template passiert das automatisch beim Start. Überall sonst musst du selbst dran denken.

Der Klon ist nicht deine Installation

Falls du Journey-Skills lokal geklont hast: das ist zum Reinschauen und Weiterentwickeln da. Deine installierten Skills liegen woanders und kommen direkt von GitHub.

Änderungen im Klon wirken sich also nicht auf deine Skills aus. Sie gehen über einen Pull Request und kommen dann beim nächsten Update bei allen an.

Regeln

Das gilt für alle

So arbeiten wir

  • Alle Projekte sind privat — nur Teammitglieder sehen sie
  • Neue Projekte und Zugänge immer per Ticket
  • SSH Keys für Git-Zugang (wird im Onboarding eingerichtet)
  • Änderungen über Pull Requests — nicht direkt auf main
  • Große Dateien per Symlink auf Cloud-Storage, nie ins Repo
