Tests

Vor jeder Aenderung

bash tests/verify-setup.sh

39 Checks: Repos, Inhalte, Pages, Org-Settings, Labels, Secrets, Teams, YAML-Syntax.

Checkliste

Alle process.env.* haben env:.
Alle steps.*.outputs.* existieren.
Jeder Ticket-Typ getestet.

Regel

Nicht committen wenn Tests fehlschlagen.

Learnings

Aus Fehlern gelernt

1

User-Eingaben nicht blind vertrauen

Automatische Quelle nutzen wenn verfuegbar.

2

Jeden Ticket-Typ testen

Nicht nur den der geaendert wurde.

3

Kein JSON in Bash

JavaScript fuer alles was JSON baut.

4

Alle Pfade testen

Env vars, secrets, outputs nach Refactoring.

5

Nicht-Techniker testen lassen

Formulare und Anleitungen vor dem Shipping von jemandem pruefen lassen der GitHub nicht kennt.
