GitHub und Claude Code bringen Skills, Agents und Projekt-Assets zusammen — teilbar, versioniert, im ganzen Team. So startet deine KI Journey bei Plan Net Journey.

Das Problem

Warum aendern wir etwas?

Bisher

  • Jeder arbeitet mit eigenen Prompts und Einstellungen
  • Skills und Wissen gehen verloren wenn jemand geht
  • Keine Versionierung — was weg ist, ist weg
  • Dateien per Mail/Slack hin und her schicken
  • Kein gemeinsamer Wissensstand

Mit GitHub + Claude Code

  • Skills und Agents als Code — teilbar, versioniert, nachvollziehbar
  • Alles lokal gespeichert und im Team geteilt
  • Jede Aenderung nachvollziehbar (wer, wann, warum)
  • Grosse Dateien ueber Cloud-Storage verlinkt
  • 50+ fertige Skills im Marketplace
Die Bausteine

Was wir nutzen und warum

Vier Werkzeuge, jedes mit einem klaren Zweck.

GitHub

Plattform auf der unser Code und unsere Skills leben. Industriestandard fuer Versionierung. Jede Aenderung ist nachvollziehbar, nichts geht verloren, und alle arbeiten auf dem gleichen Stand.

Claude Code

KI-Assistent der direkt mit deinen Dateien arbeitet. Anders als die normale Claude Chat-App kann Claude Code Dateien lesen, bearbeiten und Befehle ausfuehren.

SSH Keys

Verschluesselter Zugang zu GitHub ohne Passwort. Sicherer als Passwoerter, funktioniert automatisch, wird einmal eingerichtet und laeuft dann.

Cloud-Storage

Grosse Dateien (Videos, PPTX) bleiben in Box/OneDrive. Das Projekt verlinkt darauf. Git ist nicht fuer grosse Binaerdateien gemacht.

Alles per Ticket

Wie funktioniert ein Ticket?

Egal ob Org-Zugang, neues Repo oder Berechtigungen — der Ablauf ist immer gleich.

1

Ticket erstellen

Formular auf GitHub ausfuellen. Klare Felder, kein Freitext.

2

Admin benachrichtigt

E-Mail von GitHub. Kein Slack, kein Anrufen.

3

Admin gibt frei

Antwort mit /approve. Ein Wort — fertig.

4

Automation laeuft

Einladung, Repo oder Zugang — automatisch.

5

Ticket schliesst sich

Zusammenfassung was passiert ist. Dokumentiert.

Vier Ticket-Typen

Org-Zugang →

Neues Teammitglied braucht Zugang.

Neues Repo →

Privates Repo mit Template.

Repo-Zugang →

Schreibzugang zu bestehendem Repo.

Feedback →

Was sind Skills?

Claude Code: Skills, Agents und Projekt-Kontext

Mehr als ein Chatbot — ein Arbeitsumfeld das sich an euer Projekt anpasst.

Skills

Wiederverwendbare Anweisungen fuer haeufige Aufgaben. Wie Rezepte die Claude befolgt.

Beispiel: /campaign startet die Kampagnenplanung.

Agents

Spezialisierte KI-Persoenlichkeiten fuer bestimmte Arbeitsweisen.

Beispiel: Rook prueft eure Ideen auf Schwachstellen.

Projekt-Kontext

Claude liest automatisch die CLAUDE.md im Projekt und versteht den Kontext.

Merkt sich auch Dinge zwischen Sessions ueber MEMORY.md.

Warum ist das besser als einzelne Prompts?

Ein Prompt geht verloren. Ein Skill ist versioniert, geteilt, getestet und verbessert sich ueber die Zeit. Wenn jemand einen besseren Weg findet, profitieren alle.

Muss ich programmieren koennen?

Nein. Skills sind Markdown-Dateien mit Anweisungen in natuerlicher Sprache. Claude Code hilft dabei.

Regeln

Das gilt fuer alle

Immer

  • Alle Repos sind privat
  • SSH Keys fuer Git-Zugang
  • Neue Repos nur per Ticket
  • Grosse Dateien per Symlink, nie ins Repo
  • Aenderungen per Pull Request

Nie

  • Oeffentliche Repos erstellen
  • Passwoerter / Tokens committen
  • Videos oder PPTX ins Repo
  • Direkt auf main pushen
  • Skills mit Kundendaten in den Marketplace
